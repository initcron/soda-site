# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-11-23

### Added
- Build-time prerendering: every route is written to static HTML with its own title, description, canonical URL and Open Graph tags, so crawlers and link previews see content and deep links return 200.
- `sitemap.xml`, and a `Sitemap` line in `robots.txt`.
- Get LearnForge page, with the download marked as coming soon.
- Links config for the Hub buy page, certificate check and app download; optional `hubSlug` per course.

### Changed
- Course enrol buttons come from one function: Udemy until a course has a Hub slug, then the Hub buy page. No price is shown.
- The document title now updates on client-side navigation.
- `404.html` is a real not-found page, generated by the prerender; the deploy workflow no longer copies the homepage over it.
- Certification formats are labelled as planned.
- AI/ML Foundations is marked free: its lessons and quizzes will be free in LearnForge. Free courses carry a "Free soon in LearnForge" badge, and copy names LearnForge in place of "our learning platform".

## [0.2.0] - 2026-11-23

### Changed
- Repositioned the site around production AI engineering: "Run AI in production. Safely."
- Replaced the five role paths with three flagship tracks (Agentic DevOps, AI Platform Engineering with Kubernetes, AgenticOps), a free SRE Foundations path and a Kubernetes Platform Engineering path. Old path URLs redirect.
- Redesigned the homepage, tracks listing and track detail pages; new navigation, announcement bar and footer.
- Darker ink palette with mauve as the accent, calmer typography, flat cards (see docs/color-theme.md).
- Career roadmaps are now organised by starting role.
- Client logo alt text now matches the logos shown.

### Added
- Certifications page with four planned School of DevOps certifications: Certified Agentic DevOps Engineer, Certified AI Platform Engineer, Certified AgentOps Engineer and Certified SRE/DevOps Engineer.
- Resources section: skills self-assessment, the production AI map, and a printable manager brief for each flagship track.
- For teams page.
- Specialisations: AI Security & DevSecOps, FinOps for AI & Agents, Guardrails & GRC, AI SRE.
- Track curriculum, audience, outcomes, capstone and certification data with tests.
- YouTube and newsletter links; page meta description.
