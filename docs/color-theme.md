# School of DevOps — Color Theme

Updated 2026-11-23 for the production AI repositioning. Mauve stays the brand
colour; dark sections and text moved from soft slate to a deep ink for contrast
and a more authoritative feel.

## Brand Palette

| Role | Hex | Name | Usage |
|------|-----|------|-------|
| Ink | `#131A2B` | Deep ink | Headings, body text, hero, dark bands, footer, primary buttons |
| Brand accent | `#B08A9A` | Mauve | Logo badge, favicon |
| Accent text | `#886A7A` | Dark mauve | Eyebrows, nav hover/active, mono numbers, links, button hover |
| Accent on dark | `#D9BFCB` | Light mauve | Eyebrows, highlights and accent buttons on ink |
| Background | `#ffffff` | White | Page background |
| Tinted section | `#f6f5f7` | Mist | Alternating sections |
| Free | `#E3F1E8` / `#1F6B43` | Green | "Free path" chip only |

## Text

| Hex | Usage |
|-----|-------|
| `#131A2B` | Headings and primary text |
| `#565b68` | Paragraphs and descriptions on light |
| `#c9ccd6` | Paragraphs on ink |
| `#aab0bf` | Secondary text on ink |
| `#8a90a0` | Labels on ink |

## Components (client/global.css)

`button-primary` (ink), `button-accent` (light mauve, for ink backgrounds),
`button-ghost`, `button-ghost-dark`, `card`, `card-link`, `chip`, `chip-free`,
`chip-new`, `chip-planned`, `dark-band`, `eyebrow`, `eyebrow-dark`.

Cards are flat with a 1px border and a soft shadow on hover. No rotated badges
or hard offset shadows.

## Favicon

SVG circle with `#B08A9A` background, white "S" text.
