# School of DevOps — Color Theme

## Brand Palette

| Role | Hex | Name | Usage |
|------|-----|------|-------|
| Brand accent | `#B08A9A` | Mauve | Logo badge, course badges, path card shadows, decorative accents |
| Accent text | `#886A7A` | Dark mauve | Eyebrow text, nav hover/active, mono numbers, scribble SVG |
| Dark sections | `#506580` | Soft slate | Footer, stats bar, roadmap CTA, hero orb shadow, course card shadows |
| CTA buttons | `#B08A9A` | Mauve | Primary button bg (hover: `#886A7A`) |
| Background | `#ffffff` | White | Page background, hero, section backgrounds |
| Instructor CTA | `#f2f2f2` | Light gray | Instructor banner background |

## Text Grays

| Hex | Usage |
|-----|-------|
| `#506580` | Primary body text (foreground) |
| `#5e6068` | Paragraph text, descriptions |
| `#6b6d75` | Secondary text, taglines |
| `#8a8c94` | Footer section headers, muted labels |
| `#9a9ca4` | Stats sublabels, sidebar labels |
| `#b0b2b8` | Dark-section muted text |
| `#b8bac0` | Footer description text |

## Favicon

SVG circle with `#B08A9A` background, white "S" text.
